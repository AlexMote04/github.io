GPU Sequence Alignment

Final-year project

CUDA-accelerated protein database search

Runs thousands of Needleman-Wunsch (global) and Smith-Waterman (local) alignments in parallel on the GPU. Short sequences get one thread each; long ones are split into tiled anti-diagonal wavefronts across thread blocks.

  • Automated regression tests check every GPU score against Parasail on each run, alongside Catch2 unit tests.
  • Benchmarked optimisations (coalesced memory access, inter- vs intra-sequence parallelism, hybrid kernel routing) against a naïve GPU baseline using CUDA events.
  • 5.8× vs Parasail (global)
  • 8.99 GCUPS peak
Stack
C++17, CUDA, CMake, Catch2, Parasail
When
Sep 2025 – Apr 2026

RiskDrift

Team · Competition

Detecting risk-regime shifts in SEC 10-K filings

An NLP pipeline that embeds each company’s yearly risk disclosures (10-K Item 1A) with FinBERT and flags unusually large changes in language using per-company cosine-similarity z-scores, validated against 6-month forward returns.

  • My part: the embedding module. Sliding-window mean pooling over 512-token chunks turns filings of any length into one 768-d vector.
  • Top 5 CFA AI Investment Challenge 2026, UK national final
Stack
Python, FinBERT, Streamlit, SEC EDGAR
Team
4 people · Apr 2026

High-Performance AI Hex Agent

Team · Coursework

Monte Carlo Tree Search game agent in C++

A competitive agent for the board game Hex, modelled on the champion program MoHex 2.0: Monte Carlo Tree Search with RAVE and pattern-based simulations, running in a C++ engine behind a Python wrapper.

  • My part: optimised the C++ evaluation engine with bitboards, adjacency lookup tables and a compact tree-node layout.
  • Built a benchmarking framework measuring simulations per second and the win rate of new features against the current agent.
  • 10× simulations per second vs baseline
Stack
C++17, Python, Docker

Graphics Drawing Accelerator

Coursework · SoC Design

Circle-drawing unit for a 2D graphics accelerator

I designed the circle-drawing unit of a 2D hardware accelerator in SystemVerilog. It renders circles straight into a framestore while meeting strict timing and resource constraints.

  • Testbench checks RTL output pixel-for-pixel against a high-level C++ model.
  • Integrated into a larger SoC and synthesised onto an FPGA.
  • RTL = C++ verified against reference model
